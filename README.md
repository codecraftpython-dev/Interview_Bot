# InterviewForge

> **Where every interview is forged around you.**

InterviewForge is an adaptive AI technical interviewer that builds personalized technical interviews around each candidate's learning journey, adapts to their answers in real time, and provides actionable feedback on their technical understanding.

## Core Capabilities

- **Candidate Personalization**: Constructs tailored interview strategies based on candidate profile, curriculum progress, completed missions, and learning signals.
- **Adaptive AI Evaluation Engine**: Dynamically adjusts question depth, follow-up probes, and technical difficulty based on real-time answer quality.
- **Curriculum-Aware Assessment**: Assesses RAG, vector databases, prompt engineering, agentic workflows, MCP tools, and production AI deployment.
- **Evidence-Based Technical Feedback**: Delivers structured performance reports highlighting strengths, growth areas, technical accuracy, and actionable next study steps.
